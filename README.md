# Codex Remote Bridge

**Beta 测试版 · 作者：[xiyannan](https://github.com/dizzynote-cell/codex-remote-bridge)**

项目地址：https://github.com/dizzynote-cell/codex-remote-bridge

> 主力电脑能稳定使用 Codex，但手机网络或官方移动端不方便？通过飞书或网页，随时调用自己的 Windows 主力电脑继续工作。

Codex Remote Bridge 主要面向中国大陆用户：Codex、项目和文件操作仍在主力电脑执行，手机、平板、其他电脑以及本机 PC 只需现代浏览器或飞书即可发送任务、切换对话并查看结果。

## 核心亮点

- **不暴露主力电脑**：本机桥主动连接飞书和可选云端服务，无需给家庭宽带开放入站端口，也不需要让公网直接访问主力电脑。
- **飞书授权保护网页**：网页端使用飞书 OAuth 登录，并可限制为安装者本人的飞书账号访问，避免公开网址直接暴露对话内容。
- **延续真实 Codex 会话**：可以查看、切换并继续 Windows Codex 中已有的项目和对话，而不只是每次执行一个彼此独立的临时任务。
- **任何设备都能使用**：支持飞书，也支持手机、平板、其他电脑和本机 PC 上的现代浏览器。
- **工作仍在主力电脑执行**：手机只负责输入和查看结果，实际代码、工具、项目和文件操作使用主力电脑的性能与开发环境。
- **文件主要留在本机**：云端以文字同步为主；小文件可以临时传输，大文件可通过用户自选的同步盘处理。
- **适合长期在线**：提供 Windows 托盘、开机启动、异常自动恢复、计划重启提示和服务中断提醒。
- **按需选择部署方式**：不购买服务器也能使用飞书；需要完整历史和网页输入时，再启用公网网页模式。

网页模式下，本机桥主动向云端同步文字并领取任务，云端不会直接连接、扫描或开放访问主力电脑的文件系统。

## 两种模式

- **仅飞书模式**：无需服务器，通过飞书机器人发送任务并接收进度和结果。
- **飞书＋网页模式**：增加完整历史、项目列表和网页输入；任何带现代浏览器的设备都能使用，包括手机、平板、其他电脑及本机 PC。

面向大陆用户部署网页端时，通常可优先考虑中国香港地区的轻量服务器，并使用域名和 HTTPS。服务器主要同步文字，不应默认存放项目文件。

## 安装前准备

完整引导约 6 步，通常需要 10～20 分钟：

1. 检查 Windows、Codex 登录和 Python 环境。
2. 选择仅飞书或飞书＋网页模式。
3. 创建飞书自建应用并填写 App ID、App Secret。
4. 配置项目目录和大文件同步目录。
5. 配置公网服务器、域名和 HTTPS（网页模式可选步骤）。
6. 测试连接，并选择是否开机自动启动。

大文件建议通过本机同步盘交换，例如：

```text
D:\BaiduSyncdisk\Agent Disk
```

也可以使用 OneDrive、坚果云、Dropbox 或其他能同步为本地文件夹的产品。小文件可通过飞书或网页临时上传。

## 安装与启动

用户只需要双击根目录的 `Codex Remote Bridge.cmd`：首次运行自动进入安装向导，配置完成后启动托盘；以后再次运行只会打开托盘并确保桥在线。真实密钥、日志、会话数据和上传文件不会提交到 Git。

## 运行与自动恢复

- `Codex Remote Bridge.cmd`：唯一的普通用户入口。
- 启动、停止、计划重启、网页、日志和开机启动都在托盘右键菜单中管理；选择 Exit 会先停止桥服务，再退出托盘。
- 桥意外退出时，守护程序会在 5 秒后自动重启。
- 可通过控制台启用 Windows 登录后自动启动。

主力电脑必须保持开机、联网，并维持 Codex 所需的网络环境。这个工具不是远程桌面，无法代替处理验证码和系统交互弹窗。
