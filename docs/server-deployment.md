# 网页服务器部署

网页模式需要公网服务器、域名和 HTTPS。面向中国大陆用户时，可以考虑中国香港地区的轻量服务器；请根据所在地法规、云厂商规则和实际网络质量自行选择。

服务器需要 Linux、Python 3.11+、域名、HTTPS 反向代理，以及 `cloud/.env.example` 列出的环境变量。

腾讯云 CLI 是可选管理工具，不打包进项目。安装向导仅在用户明确选择时，通过 `python -m pip install tccli` 安装。

## 认证失败限流

云端后台包含 `auth_rate_limit.py`。同一来源在5分钟窗口内连续认证失败8次，第8次即返回 HTTP 429，并在之后10分钟拒绝未认证请求；响应包含 `Retry-After` 和剩余等待秒数。成功认证会清除该来源的失败计数，已有有效登录和正确设备同步令牌始终允许通过。浏览器认证与设备认证分别计数，不使用系统防火墙封禁，因此不会封锁同机其他项目。

计数只保存在当前后台进程内，重启后清空，不是抵御分布式攻击的全局 WAF。主力 PC 离线、飞书服务暂时不可用等上游错误不视为错误密码尝试。

后台应保持监听回环地址，通过 Caddy 提供 HTTPS。仅当直接连接来自回环代理时才使用 `X-Forwarded-For` 的最右侧地址；代理必须覆盖或追加真实连接来源，不能直接信任访客自报的地址。若额外增加 CDN 或其他代理，应先核对真实 IP 信任链，避免让所有用户共用代理 IP 的失败计数。

升级时同时部署 `app.py` 和 `auth_rate_limit.py`，并在维护时间重启本项目的后台服务。不得为了启用本功能重启整个服务器、修改全局防火墙或影响其他项目。
